# тут документация

### Запустить astro airflow

```
astro dev start
```

### Просмотром логов в реальном времени:
```
astro dev logs -f
```

### Остановить astro

```
astro dev stop
```

### Полное уничтожение среды

```
astro dev kill
```

### Пересобрать образ

```
astro dev restart
```
